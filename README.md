# challenge-tracker

Сайт для личных челленджей: заводишь челлендж — получаешь таблицу дней и отмечаешь выполнение.

## Идея

Хочу «30 дней отжимаюсь» — и вижу сетку из 30 клеток. Кликнул по сегодняшнему дню — отметка
поставлена, серия выросла. Никаких рассуждений про мотивацию: только таблица, отметки и
видимый прогресс.

Что должно быть:

- **Челлендж** — название, длительность (например, 30 дней), дата старта.
- **Отметки** — клик по дню ставит/снимает галочку.
- **Прогресс** — сколько дней выполнено, текущая серия, лучшая серия.
- **Несколько челленджей** — каждый на своей вкладке.
